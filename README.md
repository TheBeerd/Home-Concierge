# Home Concierge

A concierge-model marketplace for DFW HVAC: human-reviewed AI intake, structured contractor bids, and a decision memo — instead of a pay-per-lead chatbot. See [`docs/product-model.md`](docs/product-model.md) for the full product/business model and [`docs/contractor-onepager.md`](docs/contractor-onepager.md) for the contractor-facing pitch.

## Repo layout

- [`mobile/`](mobile/README.md) — the iOS-first Expo (React Native) app: the four core screens (Home, Guided Intake, Decision Memo, Job Status).
- [`docs/`](docs) — product model, contractor one-pager, and the approved wireframe (`wireframe.html`) the app is built against.

Start with `mobile/README.md` to run the app.
